# My Map — 京都の乗換案内

Yahoo!乗換案内の実際の結果と、市バスの接近表を取得し、アプリ独自の日本語UIで表示します。利用者からYahoo!の二次利用承諾取得済みとの申告を受け、その前提で実装しています。再利用・公開範囲は取得した承諾条件に従って運用してください。

公開アプリ：https://at5tram98-hash.github.io/kyoto-transit/
ソース：https://github.com/at5tram98-hash/kyoto-transit

## 主検索

- 出発・到着・最大3つの経由地、日時、近鉄の普通／急行、乗換余裕、徒歩上限を入力。
- Cloudflare WorkerがYahoo!の公開検索結果HTMLを取得。アカウント・Cookie情報は利用しません。
- 時刻、列車・系統、行先、番線・のりば、途中駅と時刻、通常運賃、乗換回数を正規化し、My Mapの経路カードとして表示。検索後の別タブ移動は不要です。
- 返された候補から、対応路線・列車種別・乗換余裕・明記された徒歩時間で絞り込みます。普通／急行は取得候補のフィルターであり、普通の候補が返らない時間帯に架空便を作りません。
- 早い／乗換少／待ち少／歩き少で比較。最大3候補を保持する近似探索であり、全ダイヤの最適解は保証しません。
- 経由地では必ず下車。実到着時刻に、指定滞在（0〜180分）と乗換余裕の長い方を加え、次の区間を自動検索。翌日への繰り越しにも対応。
- 通常運賃は各区間のYahoo!検索結果を使用。折り返しの精算条件は乗車券によって異なるため、区間ごとの片道運賃合算は目安です。
- 対象外の路線、未取得の時刻・運賃、取得障害を架空の値で補完しません。
- 検索条件・場所のお気に入り、経路コピー、設定バックアップ／復元、ライト／ダーク対応。

バス検索は公式の長い停留所名と会社名を渡し、同名施設との混同を防ぎます。Yahoo!が対象外の路線しか返さない場合、候補なしになります。地下鉄東西線・JR・京阪・阪急などは表示対象外です。

## 現在地・いつもの行先・合流

- 「取得」を押すとGeolocation `watchPosition`で更新。緯度経度はメモリー内だけで処理し、保存・送信しません。検索サーバーへ渡すのは対応する地点IDと検索日時です。「停止」、ページを閉じる操作で追跡を解除します。
- 国土交通省の国土数値情報（鉄道2025・バス停留所2022、CC BY 4.0）を加工し、42駅・市バス181停留所・京都バス2地点と線路形状を収録。バス停位置は上下を統合した代表点です。名称変更は2026年の停留所カタログへ対応付けています。
- GPSの精度100m超・45秒より古い位置・対応エリアから5km超は自動の出発地点に使用しません。線路付近は乗車中の確定ではありません。路線外では最寄りの対応市バス停の接近情報を取得。のりばと行先は選択して確認できます。
- 京都産大は主検索・行先ボタン・友達との合流の全てで国際会館経由。京都バス40系統／直行40以外の大学行き経路は採用しません。
- 無印良品／GUは店舗名と対応範囲内の最寄り駅・停留所を端末内で登録できます。店舗は推測して設定していません。店舗までの徒歩は別途確認してください。
- 友達の高の原発の実列車を日時・種別・行先で選択。自分の出発駅・時刻から、友達の実停車駅を一緒に乗れる時間の長い順に比較し、乗換余裕と指定最低待ち時間の両方を確保。到着・発車・待ち・必要余裕・残余裕・共同乗車時間・比較駅を表示します。
- 合流後の再検索でも発車時刻・行先・種別・区間終着時刻を照合し、選択した友達の便と一致する結果のみ採用。取得に失敗した駅を「不可」と断定せず未確認にします。最大地点は返された候補の中での最大で、全列車の最適解ではありません。
- 路線付近では列車候補を取得し、GPS・移動方向・実際の停車時刻を照合。列車を確認すると次の実停車駅と予定到着時刻を表示します。地下のGPS停止や遅延は自動的に確定・補正できないため、手動確認を残しています。

## 定期券と運賃の計算

市バスフリー、京都バス40の対象区間、地下鉄の国際会館〜京都を初期設定。範囲内は「0円（定期）」、通常運賃も併記します。京都バスも有効という利用者申告に基づく設定です。近鉄は無料にしません。

通常運賃はYahoo!の値をそのまま保持します。完全に定期内なら0円、定期の適用なしなら取得した通常運賃です。一部だけ地下鉄定期に覆われる連絡区間は、登録距離・運賃表から追加額を算出し「目安」と表示します。乗継割引・特殊な乗車券・折り返し精算の最終額は事業者の案内を優先してください。有効期限を設定した場合、その翌日以降は適用解除。

## 接近・運行情報

- ポケロケ plus+から対象停留所の系統・行先・のりばを取得し、選択した接近表の描画済みHTMLを読み取ります。
- 接近表内の画像の代替文字から「何停留所前」「混雑」を独自カードで表示。凡例は読み取り対象外。
- 「6停留所以内に接近なし」は公式メッセージを確認した場合だけ表示。空表・読み込み失敗を接近なしと扱いません。到着までの分数は推計しません。
- 原画像を取得して日本語OCRで確認する機能も継続。近鉄の運行画面と手元の画像はTesseract.js 7のOCRで読み取ります。
- 取得時刻を表示し、2分を過ぎた情報は保存情報として表示。運行情報の掲載なしから定刻運行を推測しません。
- 更新操作・現在地の最寄り地点の変化で取得。自動取得は最短60秒間隔。サーバーは8リクエスト／分／IP、最大12上流検索／通常経路検索、合流検索には回数上限、タイムアウト・読み込みサイズ制限あり。
- 接近画面とホームの接近カードに「1分ごとに更新」を用意。表示中の画面だけ更新し、非表示・別タブ・取得中には更新しません。行先を切り替えると前の行先の表示を消して自動取得。保存情報も停留所・行先が一致する場合だけ復元します。
- GPSを使えない場合も、ホームで市バス停を手動選択すると行先ボタンと接近情報を同じ画面で利用できます。取得が時間切れになった場合は再取得を案内します。
- 任意URLやブラウザー認証情報は受け付けず、取得するサイトと地点を限定。検索クエリはログから除去。設定・画像は端末内へ保存。
- Cloudflare無料枠のブラウザー利用上限や公式サイト変更・障害時は取得に失敗することがあります。有料プランへの自動変更はしません。

## 開発用シミュレーション

折りたたまれた「試作のルート比較」は架空ダイヤのUI検証用です。実検索とは分離され、取得失敗時のフォールバックには使いません。任意時刻JSONの取込も試作機能のみを変更します。実際の乗車判断には主検索を使用してください。

## データの注意点

通常ダイヤはYahoo!、市バス接近はポケロケ plus+、近鉄運行は公式運行画面です。各取得時刻を併記します。徒歩は検索結果で明記された区間のみ、構内移動は待ち等に含まれます。運行変更やリアルタイム遅延で検索ダイヤから変わることがあります。二次利用の承諾範囲に表示義務・アクセス頻度等が指定されている場合は、その条件に合わせて設定してください。

### 乗車アシスト（2026-10更新）

- 近鉄京都線は指定の公式列車走行位置ページをサーバーで実際に開き、駅／駅間、方向、普通・急行、行先、遅れ、公式更新時刻を取得。My Mapの列車マークで表示。京都〜大和西大寺の範囲のみで、地下鉄・奈良線の位置はこの画面に含まれない。
- 位置・速度・方位・軌跡、Yahooの実検索便、取得済みの接近／列車位置を点数化。確率ではなく一致度（0〜100）。直近20分と5分の2時刻の検索候補を統合し、候補は最大3件、手動確定を優先。車両IDがない接近情報だけで同じ便と断定しない。
- 自動モードは3.5m/s以上＋20秒以上の路線付近の移動を要求し、変更は30秒、停車地点付近での停止は20秒継続を要求。バスの道路形状は未収録のため、取得した停留所の順序を結ぶ区間で照合。自転車等との完全な区別を保証しない。根拠と閾値は画面の折りたたみに表示。
- 手動で選んだ便はGPSが途切れても維持。駅で位置確認できた予定時刻と実時刻の差、または選択した便の予定時刻から経過時間を計算。到着は推定／予定を明示し、近鉄の照合候補の遅れもその旨を明記。
- バス・電車は降りる停留所／乗換駅を選択可能。通知はアプリを開いている間の画面表示と対応端末の振動。車内の物理的な降車ボタンは自分で押す必要がある。バックグラウンドのプッシュ通知ではない。
- 途中停留所の時刻がない場合は架空の時刻を補わず、確認できたGPSの通過停留所に基づいて更新。残りの数は取得済み・登録済み停車地点に限定。
- 乗車前は近い市バス3停留所を距離順に表示。位置図（道路なし・北が上）、ここから出発、接近情報、選択した行先に合うYahoo検索候補の次の予定便を表示。全方向・全便の停留所時刻表とは異なる。
- GPS座標は端末メモリのみ。検索には対応停留所IDだけを送信。取得停止／ページ終了時に軌跡を破棄。リアルタイム表示の自動更新は1分ごとで、非表示・取得中は停止。情報が2分以上古ければ表示。

### 画面とGPSの簡素化（2026-10-10）

- 起動時は「いま」を表示し、GPS監視を自動開始します。ブラウザによる位置情報の許可が必要です。拒否後は自動で要求を繰り返さず、「再取得」で再試行できます。
- 一時的な取得エラーで監視を停止せず、ページから離れると解除、戻ると再開します。位置・速度・方位は端末内だけで扱います。手動の出発地指定でもGPSは継続します。
- 乗車判定に合わせて、周辺の停留所／バス乗車中／電車乗車中の画面を自動で切り替えます。手動確定した便は地下でも維持します。
- 乗車中は次の停車地点・予定時刻・残り・降車通知を中心に表示。候補の点数、判定理由、地図、手動操作は必要なときだけ開けます。
- 検索、接近情報、設定は独立した画面です。友達への合流と勤務地の行先は「いま」に残しています。
- バスは緑、地下鉄は青緑、近鉄はオレンジ。端末のシステムフォントと統一したSVGアイコンを使用し、Appleの商標アイコン画像を転載していません。
