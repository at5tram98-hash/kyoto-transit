# v3再設計・実装と検証

基準: [ユーザー指示全文](reference/mymap-v3-redesign-2026-10-14.txt)、main `ff6e8bd` / 公開build `af4813c8cc67`。v3の5タブ、大幅な情報設計変更、別便Sheetを以前の4タブ・便選択Pushより優先する。既存の探索・交通データ・乗車・折返しモデルを利用する。

## 実装前の画面設計

現状は4タブ、今の簡易検索と検索Pushの二重フォーム、右上のグローバルメニュー、日時をフォームへ再移動する補正、全駅リストと常時展開された接近詳細がある。これらの表示・DOM補正の責務を各画面Controllerへ戻す。

```text
今: 検索入口 / 近くと次便 / 乗車Hero → 停車駅・遅延・列車位置・地図
検索: 発着 / 日時Sheet / 条件Sheet → 結果 → Journey Rail
                                          └ 発車時刻 → 別便Sheet → 再計算・反映
                                                         └ その他の便 → 全便と比較
時刻表: よく使う / 近く / 路線 → 駅時刻表 → 便時刻表
運行: 現在の移動の影響 / 関係路線 / 全路線 → 公式詳細・接近
その他: 保存場所・経路 / 定期・通知・自動判定 / 表示・出典・詳細設定
```

|用途|配置|
|---|---|
|次駅・降車・次行動、近くの次便|Main|
|経路結果・Journey詳細・全便比較・停車駅・遅延・列車位置・設定詳細|Push|
|日時・条件・短い便選択・降車設定、場所の次便|Sheet（medium/large）|
|地点候補入力・詳細地図|Full Screen|

## 状態・色・Motion

- 5タブを既存NavigationとHistoryへ統合。検索Rootは単一のフォームを所有し、今タブへのフォーム複製やDOMの往復移動を廃止。従来の検索履歴・保存・復元を再利用する。
- 日時・条件は同じformのコントロールをSheetに所有し、同じ設定のStoreを増やさない。便選択は既存の便識別・version照合・後続再探索を使う。失敗時は元経路を維持する。
- Semantic Colorを共通Tokenに定義。地下鉄/近鉄/市バス/京都バス/徒歩/直通と、実測/予測/予定・遅延・選択を別の意味で扱う。公式資料の色とMyMapの識別用色を混同しない。
- Push/Pop 320ms、Tab crossfade、指への1:1追従、Sheet detent/snapを共通Motionに集約。Reduce Motionでは短いfade。ネイティブscrollを維持する。
- 非表示画面の取得停止、検索・スクロール・便選択状態の保持、既存最大5画面cacheを維持する。

### Color / Surface / Typography

`vnext.css` にLight/DarkのBase、Transport、Status、Surface、Materialと文字tokenを集約した。色だけに依存せず、交通アイコン・事業者名・種別・sourceラベル・警告文も表示する。競合アプリや事業者のブランドそのものを複製した色ではなく、交通識別用のMyMap semantic色である。

|烏丸線|#467b21|#9dcf64|badge・Journey Rail・Hero 8% tint|
|近鉄|#ac5a00|#ffb65c|badge・種別marker・Rail|
|市バス|#00796b|#65cdbb|系統・路線chip|
|京都バス|#b23c55|#ff92a8|市バスと区別するbadge・Hero|

本文はsolid surface、Toolbar/Tab/Sheet操作部はmaterial。Hero 26px、候補20pxを基本にし、設定・接近を1件ずつcard化しない。Large Title34px、Hero32px、arrival24px、Body17px、Secondary15px、Caption13pxのtokenを使用。Tabラベルは5項目を維持するため13〜16pxの範囲で拡大し、本文の200%と同じ比率で膨らませない。小地図の凡例や図中補助文字は専用サイズを保持する。

### Navigation / Motion / State

5独立Stackと既存hash URL/History APIを統合。Push/Pop320ms、Tabと同一階層更新はcrossfade、Swipe Backは1:1追従、距離／速度によるcommitとcancelを維持。Sheetも高さ・位置・backdropを指に追従させ、close時は残るAnimationをcancelする。Bodyスクロールはブラウザー標準、scrollTop0かつ下方向だけSheetへ渡す。

1本前後で結果画面を更新するときは同じ深さのHistory entryをreplaceし、重複した戻り先を作らない。検索入力・sort・結果・途中駅展開・地図zoom/pan・Tab・独立scroll・フォーカスを保持。元のfocus Nodeが再描画されても、安定したID/属性から復元する。乗車や準備した旅程が意味的に変わった場合だけNowを主要情報へ戻す。

非表示では停留所preview・地図・必要なpollingを停止し、Screen cacheは5まで。市バス公式予定fallbackは同日・系統・行先／方面が照合できる時だけ利用し、stop数から架空の分数を生成しない。京都バスの同名停留所に市バスRealtimeを混ぜない。GPS更新でも近隣ボタンと乗車操作はkeyで保持する。

### 別便の計算保証

短いSheetと全便比較は既存の同じtrip選択pipelineを使う。後続乗車・徒歩・滞在・buffer・到着・全区間運賃・定期・案内IDを再計算する。freshなexact observationが得られる場合は対象便を反映して後続も再探索する。便ID／serviceId／運行日一致、90秒以内の観測だけを乗車案内へ橋渡しし、公式時刻に二重加算しない。失敗や古い非同期結果は元の経路を保持する。

## 資料との判定・限界

|Task|検証した操作と条件|
|---|---|
|A|GPSが有効で丸太町付近、当日出発、国際会館候補あり：今→検索→目的地入力→候補→検索の4tap。文字入力のキー数は含めない。日時変更が必要な条件まで4tapとはしない|
|B|結果から1本後の再探索が1tap。更新後のBackは検索へ1回で戻る|
|C|経路詳細の発時刻→短いSheetの別便選択の2tap。後続時刻・料金・案内を再計算。初回取得時間やその他の全便比較は別条件|
|D|GPS・市バスデータあり：今の近隣に204の次便を表示、追加0tap|
|E|停留所Sheetに次便と路線chip。chip選択で絞込み、全接近へ1tap。取得がない場合は予定／未取得表示|
|F|運行の最上部に対象路線の公式状態。正常、注意、遅延、未取得を区別|
|G|乗車画面の次駅と自分の降車駅。390×844・100%では降車表示がTabより上。文字拡大では内容に応じてnative scroll|

v3のUI・フローを実装したことと、全世界の交通網や競合全機能と同等になったことは異なる。一般住所／POI、乗車位置／出口、始発／終電の網羅性、施設バリアフリー、構造化運休の自動回避は未整備。施設候補は既知の京都産業大学に対応する登録停留所に限定。始発badge／番線はデータがある場合だけ表示する。京都バスODPTはoptional未設定のため実測と表示しない。

## 検証と証拠

ブラウザー画像は固定時刻・GPS・公式形式の検証feedを使うため、交通精度の実地測定ではない。本番実接続確認は別の記録にする。競合は公式ヘルプ／紹介画面と比較し、競合iPhoneアプリの実機座標・モーションを測定したとはしない。

- 自動検証：`npm run check`、モデル340件、34画面×8状態の座標監査、v3 Task A〜G、既存Journey/Navigation/折返し/GPS/PWA/実地理の回帰。最終実行値と公開版は後段に記録する。
- 座標監査：390×844 Light/Dark・文字100/150/200%、805px。44px操作領域、独立action8px間隔、末尾chevron、clipping／collisionを検査。旧quick-searchは重複を廃止したため、新しい日時Sheetへ置換した34画面。機能削除の意味ではない。
- v3固有：High Contrast、Reduce Motion、Browser/Standalone相当、日時Sheet medium/large・20pxの1:1追従、模擬keyboard時にSheetとCTAが可視範囲にあること。
- Navigation：App/Browser/Swipeの親一致、30%cancel・50%commit・flick・pointercancel、縦scroll/Map/Sheet/Tab競合、scroll/input/zoom/Tab/reload保持。
- PWA：更新待ちで案内を保持、更新後復元、旧clientのmodule整合、offline、失敗したprecache、旧公開workerからの移行。
- 未実測：物理iPhoneのOS Edge Back、実ソフトウェアキーボード、VoiceOver、Haptic、実地GPS／乗車精度。自動ブラウザー合格をこれらの合格へ置換しない。

## 最終検証記録
