## 実装と実測を区別する制限

地下鉄の位置は時刻表上の推定、近鉄の到着は照合できた場合の予測。欠測を埋める架空の便や位置は生成しない。市バス公式お知らせの取得復旧は、すべての便の現在の遅れを公式確認できるという意味ではない。京都バスODPTの外部設定、物理iPhone/VoiceOver/OS Edge、実車の検知精度は今回のクラウド試験では完了しない。従来のGlobal Release Ready / 全仕様100%の未達を消さない。

## 次回の作業メモ

UIは古いYahooフォーム主体の今画面へ戻さず、今回の21注釈と5タブを基準にする。表示時刻・停留所数・位置の観測/推定/予定を区別する。新しい接近詳細はroute番号だけで識別しない。画面を離れた後はControllerのpollingを停止する。Pointerのfocus枠除去とkeyboard focus-visibleは共通Controller/CSSで扱い、各画面にoutline上書きを追加しない。新規Navigation・Storeや、旧UIをhiddenで残す実装を増やさない。
